## 1. What the campaign is

This is a Whop-style clipping campaign. You cut short vertical clips from footage the campaign supplies, post them on TikTok and/or Instagram for the Arabic-speaking MENA audience (Gulf viewers especially), and get paid per view once a clip is approved.

| | TikTok | Instagram |
|---|---|---|
| CPM | $1 / 1,000 views | $1 / 1,000 views |
| Minimum views to qualify (per clip) | 2,000 | 3,000 |
| Max payout per clip | $300 (≈300k views) | $150 (≈150k views) |
| Required Gulf audience (KSA, UAE, KW, QA, BH, OM) | ≥ 30% of the countries shown in analytics | ≥ 20% |
| Account tag | `@callofdutyarabic` | `@callofdutyara` |
| Extra | n/a | Repost 🔂 the official reel (watch it fully first) |

Payout is per clip, not cumulative. The 24–48h review starts only after you send a **screen recording** of that clip's analytics in support chat, filmed exactly like the reference videos.

You can use an existing account, and you don't need to delete old videos.

### Hard source rules
- **Podcast = split-screen only.** Podcast on **top**, a streamer clip on the **bottom**, **audio from the podcast only**. The rules doc says this for EP 01; the sources doc says it for both episodes. **Apply it to both.**
- **Never use footage that shows Mads Mikkelsen.** Scrub every source for him before you cut.
- **The Basharkk stream title is negative** ("is the game frustrating? 👎"). Only use positive or hype moments from it. Never use the title framing or any complaints, because negative talk about MW4 means rejection.
- No gameplay you recorded yourself, no outside clips, no third-party logos or watermarks (this includes the CapCut end-card and TikTok/Twitch watermarks on re-uploads).

## 3. Content rules → compliance checklist

Run through this before **every** post:

**Video**
- [ ] Only footage from the allowed sources; no Mads Mikkelsen
- [ ] Podcast clips are split-screen (podcast top / streamer bottom / podcast audio only)
- [ ] ≥ 10 seconds long
- [ ] Shows gameplay, new features or dev milestones in a positive, exciting, shareable way
- [ ] Doesn't misrepresent the game or show features that don't exist
- [ ] Doesn't name any game other than Call of Duty
- [ ] No long or boring explanation; it gets to the hook fast
- [ ] On-screen text is **Arabic**
- [ ] No political, hateful, controversial, adult or illegal content
- [ ] No outside logos, watermarks or IP

**Audio**
- [ ] Only the approved audio from the sources (the footage's own audio / the provided file)
- [ ] No copyrighted music, no outside SFX, **no voiceover**
- [ ] Don't add trending TikTok/IG sounds (that counts as outside audio)

**Caption / post**
- [ ] Caption is in Arabic, short and natural (**no long AI-generated text**)
- [ ] The **first** hashtag is the ad disclosure: `#إعلان` (or #Ad / #Sponsored / #Advertisement / #إعلان_مدفوع)
- [ ] Tags the official account: TikTok `@callofdutyarabic` / IG `@callofdutyara`
- [ ] Likes and comment counts are **visible**, and comments are on
- [ ] Follows the platform's policies (also use the platform's own "branded content / paid partnership" toggle where available)
- [ ] IG only: the official reel has been watched fully and reposted (once per account)

**Growth**
- [ ] No paid boosts (TikTok Promote / IG Boost), no engagement pods, no bought views, no cross-promotion of any kind

## 4. Main risks & how to handle them

| Risk | Why it matters | Mitigation |
|---|---|---|
| **Gulf audience % too low** | Biggest rejection risk, since it's checked on every clip | Post at Gulf prime time (≈ 19:00–23:00 KSA, UTC+3). Use Gulf-dialect captions and text. Add Gulf/Arabic gaming hashtags (e.g. `#كود` `#كول_اوف_ديوتي` `#السعودية` `#قيمر`). Use an account whose existing audience is already Gulf/Arabic. Don't run a VPN. Check per-clip country analytics after 24h, and if an account trends non-Gulf, stop posting campaign clips on it |
| Podcast format mistake | Instant rejection | Keep a fixed split-screen template (see §5) and never change it |
| Negative framing from the Basharkk stream | "Negative or misleading talk" rule | Cut only hype, reaction or highlight moments |
| Watermarks from the editor or downloads | Outside watermark rule | Download clean source files from Drive or Telegram, not re-uploads, and export without the editor watermark |
| Analytics proof in the wrong format | Review blocked | Copy the reference recordings step by step (TikTok: "طريقة تصوير الإحصائيات (تيكتوك).mp4"; IG: "VID_20261101_203251_228.mp4") |
| Rules change mid-campaign | Content made under the old rules gets rejected | Check channel announcements and email daily |
| Discretionary rejection | Admin can reject without giving a reason | Stay well inside every rule and spread effort across many clips |

## 5. Production plan

### Phase 0: Setup (day 0)
1. Download every source into a local `sources/` folder (Drive first, Telegram as backup).
2. Watch the reference "مثال.MOV" (split-screen example) and both analytics-recording examples.
3. Pick the accounts (1 TikTok + 1 IG at minimum) and confirm their audience is mostly Arabic/Gulf.
4. On Instagram, watch the official reel fully, then repost it: https://www.instagram.com/reel/DY4wY_vCO0X/
5. Build two editor templates (CapCut/Premiere/ffmpeg, 1080×1920, 30fps):
   - **Template A: Standard:** a single source clip, an Arabic hook text at the top, Arabic subtitles.
   - **Template B: Podcast split:** podcast 1080×960 on top, streamer clip 1080×960 on the bottom, streamer audio muted, Arabic subtitles of the podcast speech.

### Phase 1: Moment mining (day 1)
Go through each source and log timestamps in a sheet: `source | start | end | type (hype / feature / funny / reveal) | Mads? | negative? | idea`.
- **Podcast EP01/EP02:** look for "secret reveal" moments, hot takes about MW4 features, funny reactions → Template B
- **Kydra / Basharkk streams:** look for clutch plays, loud hype reactions, first impressions of new features → Template A, or as the bottom half of B
- **General sources and "فيديو جديد.mp4":** trailer beats, new features, dev milestones → Template A

Target 30–50 candidate moments.

### Phase 2: Editing (ongoing)
- Hook in the first 1–2 seconds (big Arabic text, e.g. "أقوى لقطة في MW4 🔥", "فيصل كشف سر MW4 😳").
- Length 10–30s (10s is the minimum). Short loops do well on TikTok.
- Burn in Arabic subtitles. Use original audio only.
- Export at 1080×1920 with no editor watermark.
- Run the §3 checklist on every export.

### Phase 3: Posting cadence
- Post 2–4 clips/day per platform, spread across Gulf evening hours.
- Caption format (short, natural, Arabic):
  ```
  #إعلان لحظة جنون في مودرن وارفير 4 🔥 @callofdutyarabic #كود #MW4 #كول_اوف_ديوتي
  ```
  (Use `@callofdutyara` on Instagram. The disclosure hashtag always comes first.)
- Don't post near-duplicate clips back to back. Vary the source, hook and moment.

### Phase 4: Tracking & submission
For each posted clip, track: `platform | URL | posted at | views | Gulf % | status (pending / submitted / approved / rejected) | payout`.
- After 24–48h, check views against the minimum (TikTok 2k / IG 3k) and the Gulf % (30% / 20%).
- Once a clip qualifies, record the analytics exactly like the reference video and send it in support chat.
- Wait 24–48h for review, then record the result.
- Every week, double down on the formats and sources with the best Gulf % and views. Drop the ones that keep failing.

### Phase 5: Iterate
- Review which hooks, sources and posting times give the most views **and** Gulf share.
- Recheck the rules docs for updates before every batch.

## 6. Optional tooling for this repo

To speed up production, this repo can hold:
1. `scripts/split_podcast.sh`: an ffmpeg script that builds the required podcast split-screen (top/bottom, podcast audio only, 1080×1920).
2. `scripts/cut.sh`: cuts a source clip from a timestamp list and reframes it to vertical.
3. `tracker.csv`: the moment log and post tracker from Phases 1 and 4, plus a small script that computes expected payout (`min(views/1000 × $1, cap)`) and flags clips under the view or Gulf-% thresholds.
4. `CHECKLIST.md`: the §3 checklist on its own, to tick off per post.

Arabic on-screen text and subtitles are easiest in CapCut. ffmpeg `drawtext` needs a build with libfribidi/libharfbuzz to render Arabic correctly.
